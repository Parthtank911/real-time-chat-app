# Real-Time Chat App

A **real-time chat application** built with **Node.js, Express, MySQL, and Socket.io**.  
Supports **multiple users**, **login & registration**, and **instant messaging** similar to WhatsApp.

---

## **Features**

- User registration and login (simple, without bcrypt)  
- Real-time chat with **Socket.io**  
- Multiple users can send and receive messages simultaneously  
- Modern and responsive UI with **premium design**  
- Messages appear instantly on sender and receiver side  
- Online/offline status (optional)  
- Message history stored in **MySQL database**
